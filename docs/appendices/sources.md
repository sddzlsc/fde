## 资料使用原则

本书不是学术著作，但遵守五条纪律：

1. **双源优先。** 能交叉验证的事实，至少找两个独立来源；只有一个来源的，正文明确写「单一来源」或「据报道」。
2. **口径区分。** 公司披露、媒体报道、第三方估算、作者归纳，四种东西不混着写；同一章里出现不同口径，逐条标注。
3. **待核不用。** 原始链接被拦截、只有二手转述、细节存疑的，尽量不写；必须写时标「待核」，说明本书未取得可公开复核的一手来源。
4. **不造链接、不造引语。** 只给出能确认的链接；不确定的，写「机构 + 标题 + 日期」，让读者自己检索。凡是引号里的直接引语，都注明出处；转述一律用「据报道」。
5. **不追热点。** 案例的选择标准是「有可核实的公开信息、能说明一个机制」，而不是「最近最火」。

### 四种口径

| 口径 | 含义 | 本书里的写法 |
| --- | --- | --- |
| 公司披露 | 财报、官方博客、官方客户案例、官方新闻稿 | 「公司披露」「官方客户案例」 |
| 媒体报道 | 媒体采写的报道、访谈、播客记录 | 「据……报道」；单源加「单一来源」 |
| 第三方估算 | 研究机构、行业分析、媒体据公开信息推算 | 「第三方估算」「综合公开信息」 |
| 作者归纳 | 本书作者基于多个来源做的总结、分类或算术 | 「综合」「作者归纳」 |

### 可信度标签

| 标签 | 含义 | 阅读建议 |
| --- | --- | --- |
| **A** | 公司披露 / 官方 | 可作事实，注意厂商立场 |
| **B** | 两个以上独立来源交叉 | 可作事实，仍需看口径 |
| **C** | 单一来源、播客、自述、二手转述 | 当线索用，不作唯一依据 |
| **D** | 第三方估算、多源综合、作者归纳 | 当估算用，不作为官方数字 |
| **待核** | 付费墙、链接失效、细节存疑 | 尽量不用；本书已逐处标注 |

## 引用与更正

- **链接失效**：本书尽量少给链接；确需给出时，优先官方与原始来源。若链接失效，请以「机构 + 标题 + 日期」检索，并在贡献时告知。
- **二手转引**：媒体转引公司数据、播客转述访谈内容，都可能在传抄中失真；本书对这类来源统一降级为 C。
- **发现错误**：欢迎在项目仓库提交 issue 或 PR 纠错（见[如何贡献](/contributing)）。事实错误、口径错误、失效链接都算贡献。
- **更新节奏**：本书的数据截至 2026 年 10 月；行业变化快，引用前请核对原始来源的最新版本。
