> 这份清单不是「必须读完」的作业，而是一个**随时可查的补给站**。FDE 需要的能力横跨工程、业务和现场，没有人能把下面的内容全部读完；更有效的用法是：遇到哪个问题，就查对应的那一类，读一条、用一次、记一篇笔记。链接指向官方或原始页面，若失效，请按「机构 + 标题」自行检索。

## 怎么用这份清单

- **按阶段选**：发现阶段看访谈与业务，原型阶段看 LLM 工程，上线阶段看评测与安全。
- **先读原始来源**：报告和公司博客比二手解读更值得花时间，注意区分官方披露与第三方估算。
- **允许自己没读完**：收藏不等于欠债。一本书读三章就够用，是正常状态。

## 如果你只有一周

- **零基础**：先看《The Mom Test》前几章 + DeepLearning.AI 提示词短课，然后直接做 [Lab A](/labs/lab-a-ticket-triage)。
- **想转岗**：读《The GenAI Divide》执行摘要 + 斯坦福 AI Index 的关键图表，再准备作品集。
- **管理者**：看 Databricks 的 FDE 组织文章 + 麦肯锡《The State of AI》，对照自己公司的组织与指标。

- 这份清单是**补给站**，不是课程表；读不完完全没关系，遇到问题能查到就行。
